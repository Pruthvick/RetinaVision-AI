# Retinal Disease Detection using EfficientNetV2B0

## Overview
A deep learning system for multi-label retinal disease classification using EfficientNetV2B0. The application predicts retinal diseases from fundus images and provides Grad-CAM visualizations for explainability through a Gradio interface.

## Features

- Multi-label retinal disease classification
- EfficientNetV2B0 backbone
- Binary Cross-Entropy Loss
- Grad-CAM explainability
- Interactive Gradio interface
- Image augmentation
- Fine-tuning
